# Known limitations

- Android 1.2.6 (version code 8) adds an About Me card on Home with LinkedIn and GitHub profile links for Afraz Ahamed. The external URLs open through the device’s normal link handler.
- Android 1.2.5 (version code 7) updates the Afraz Kolkata launcher artwork to include the app name in a high-contrast gold-on-indigo plaque above the Victoria Memorial and Kolkata taxi illustration. Both legacy density assets and Android adaptive icons use the branded design.
- EAS preview build `6580131b-41f3-48c8-adec-7a7399f33f64` completed on 7 Nov 2026 for Android 1.2.5. The 95,594,935-byte APK is available at `dist/AfrazKolkata-v1.2.5.apk` and `dist/AfrazKolkata.apk`, and from [the EAS install page](https://expo.dev/accounts/afrazvonlifas-team/projects/afraz-kolkata/builds/6580131b-41f3-48c8-adec-7a7399f33f64). `aapt` confirmed package `com.afraz.kolkataexplorer`, version 1.2.5, code 7; `apksigner` verified its v2 signature; EAS reported a successful build and the APK installation returned `Success`.
- Android 1.2.4 (version code 6) introduces a custom Afraz Kolkata launcher icon: a sunset Victoria Memorial silhouette with a classic Kolkata taxi in the foreground. Source artwork is maintained as SVG under `assets/`; Android uses generated density PNGs for legacy launchers and an adaptive foreground/background on Android 8 and later. This icon release does not change discovery data or app capabilities.
- EAS preview build `06c97478-4791-4fa4-9092-26806addfe92` completed on 7 Nov 2026 for Android 1.2.4. The 95,571,307-byte APK is available at `dist/AfrazKolkata-v1.2.4.apk` and `dist/AfrazKolkata.apk`, and from [the EAS install page](https://expo.dev/accounts/afrazvonlifas-team/projects/afraz-kolkata/builds/06c97478-4791-4fa4-9092-26806addfe92). `aapt` confirmed package `com.afraz.kolkataexplorer`, version 1.2.4, code 6; `apksigner` verified its v2 signature; installation on emulator `emulator-5558` succeeded.

The directory is a starting point, not an exhaustive catalogue of Kolkata. - Food and place listings are discovery leads with source labels. Verified costs/hours are available only for the named venue pages documented in `DATA_SOURCES.md`. The app does not include current reviews, menus, dish-level prices, food-safety reviews, or live availability. Those fields are not filled with guesses.
- No Supabase project or Google Places/Routes credentials were supplied. Live provider data, user accounts, saved itineraries, admin publishing, route planning, in-app maps, and live imagery require project setup and are not active. Favorites and theme preference are saved locally; itinerary stops currently remain screen state and are lost when the app restarts.
- The previous EAS APK was signed with the project’s remote Android keystore and is suitable for direct installation/testing. Keep the EAS credential private and verify signing ownership before publishing through a store.
- Emulator reproduction on 7 Nov 2026 with installed v1.2.2 confirmed tab and favorite button presses worked but route transitions from cards/home did not; launch also selected Places rather than Home. Version 1.2.3 moves the tab navigator into `app/(tabs)/`, registers details and search on a root Stack, and exposes Home as the first tab. EAS build `9505915e-ba5d-4cae-be19-2eaf07fedc48` completed successfully from commit `5880af365894e64a74fc4e67feaaf9e5b12910ff`; emulator validation confirmed Home at startup, Places and Food tabs, place and food listing details, and the Add to plan → Planner navigation. Package `com.afraz.kolkataexplorer`, version 1.2.3, code 5; APK v2 signature verified. Installable at `dist/AfrazKolkata.apk` or [the EAS install page](https://expo.dev/accounts/afrazvonlifas-team/projects/afraz-kolkata/builds/9505915e-ba5d-4cae-be19-2eaf07fedc48).
- Older ABI-specific APKs are still present as `dist/KolkataExplorer-arm64.apk` and `dist/KolkataExplorer-x86_64.apk`; they predate the current source. Use `dist/AfrazKolkata.apk`, which contains arm64-v8a, armeabi-v7a, x86, and x86_64 (minimum API 24, target API 36).
- The app does not yet query the editorial places table or provide live Places text search or map tiles. Catalog photos are attributed remote image URLs; they require network access. Generic category photos are labeled as illustrations rather than venue imagery.
- Shopping tables and documentation are present, but category recommendations, current comparable prices, reviews/moderation, and admin workflows remain planned work.
- Bus and transit data requires official/licensed source verification. No live vehicle feed, verified bus schedule, or fare database is included.
- The Nov 4 EAS failure was traced to generated `android/build/generated/autolinking/autolinking.json` containing absolute Windows package paths. Linux Gradle treated those as relative project paths. Root ignore rules now exclude Android build output, native caches, and `.git` from EAS archives; archive inspection confirmed the stale autolinking file is absent.
